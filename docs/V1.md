# Photo editor v1 acceptance

The first usable product slice is a local, non-destructive photo editor. Scene, Blender render, and workflow experiments remain available. This is not full GIMP/darktable parity.

Required for this version:

- Import JPEG, PNG and WebP; preserve originals and handle camera orientation.
- Exposure, contrast, saturation and warmth with before/after preview.
- Reversible crop, quarter-turn rotation and horizontal flip.
- Freehand/rectangle regions with independent color adjustments and attached instructions.
- Subscription-authenticated Codex proposals for supported color changes, with explicit Preview, Apply and Undo. Unsupported generative requests must be explained honestly.
- Select photos and copy a color treatment across a batch in one undoable operation.
- Export a full-size PNG/JPEG or a batch to new files without overwriting originals.
- Save/open portable project documents, restore a recovery copy after restart, keep multi-window edits consistent.
- Automated pixel/geometry/document tests plus a native import/edit/proposal/apply/undo/save/reopen/export check with exported image inspection.

Boundaries: 8-bit RGB photo processing, not a RAW pipeline or soft-proofing system. Raster generation, content-aware removal, paint brushes, layered PSD/XCF/KRA interoperability, parametric CAD, iPhone capture, and other OS acceptance remain separate milestones. AI uses the existing Codex sign-in; this v1 does not claim subscription access to the Images or Responses APIs.
